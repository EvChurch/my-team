# Concepts

## Training

### Training Module
A reusable learning unit that a volunteer can complete as part of onboarding or compliance.

### Course Page
A page within a Training Module's course-style content flow, containing authored learning material such as text, video, and question checkpoints.

### Question Block
A one-question checkpoint embedded in a Course Page, used to gather learner answers and optionally block page progress until the answer is correct.

Question Blocks are course content, not standalone quiz records. Authors add multiple Question Blocks when they need multiple questions.

### Module-Level Quiz
The older quiz concept attached to a whole Training Module rather than embedded at a specific Course Page location.

Module-Level Quizzes remain a compatibility path. New page-embedded checks should use Question Blocks so the question appears next to the material it evaluates.
